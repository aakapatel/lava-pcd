## Data provenance of the table cells

Mission table (ED Table 1 image, old ED Table 2): every cell from
`analysis_out_ed/mission_evidence.json`: duration `pose.duration_s`, path
`pose.path_length_m`, excursion `pose.max_dist_from_start_m` (given to one
decimal, 234.5 and 235.2 m; the tex has 234 and 235, and 234.51 rounds to
235, so the tex cell for flight 1 is a floor, not a rounding), vertical
range `pose.z_range_m`, planning iterations = the largest "Planning iter ->
N" in the rosout keyword hits (28 and 28), BT transitions
`bt_transitions.n_total`, local-planner failures
`failures_by_node.RunLocalPlanner` (5 and 5), validity checks
`by_node.CheckPlanValidity` with failures from `failures_by_node` (71/0,
73/0), executed segments `execution_complete.n` (43, 47), return-route
waypoints `homing_path.n_waypoints[0]` and `[-1]` (7 to 191, 6 to 202).
The row label "single recovered burst" is the tex's wording, not checked here.

Planner table (ED Table 2 image, old ED Table 3): every value from
`analysis_out/planner_params.json` (mapping, robot, planner blocks; sensor
range and ray spacing parsed from the `sensor_model` string, 0.1221 rad
shown as 0.12). That file's own `source` field says "CONFIRM with Aakash
these were the flown values, gate G2"; the table inherits that caveat. The
tex row "ESDF truncation distance 2.0 m" maps to `esdf_max_distance_m`; the
JSON also carries `truncation_distance_m` 0.6 (the TSDF truncation), which
the table does not show.

Platform table (panel c of ED2, old ED Table 1): the descriptive cells are
transcribed from `sections/extended_data.tex`. Cells taken from a JSON:
0.25 m voxels and 15 m ray integration (planner_params.json), 66.00 m
ellipsoidal-orthometric offset (datum_transfer.json, median dz). Cells
taken from the tex only: rotor span 0.8 m and all surface-survey figures
(964 images, 135 m, 2.08 km2, 7.43 million tie points, 0.48 px, 6.99e8
points, 3.08 cm, 15.6 points per m2, 9.5 cm, 14.0 cm, 7.6 cm). I checked
those against the Metashape report PDF in Birgir_data_and_papers_08_sep
(964 images, 135 m, 7,431,370 tie points, 0.476 px, 2.08 km2, 3.08 cm/pix,
699,170,586 points, 15.6 points/m2, camera total error 9.52 cm, GCP total
13.96 cm and Z 7.65 cm): all agree. The "Planning" cell now points to the
Supplementary Methods and "Supervision" to panel b, following plan/13.
